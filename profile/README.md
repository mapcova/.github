# MapCova

**Your maps. Your data. Your control.**

MapCova is an experimental open-source project exploring lightweight, self-hosted mapping infrastructure that can run on conventional PHP hosting, including shared hosting environments.

Our goal is to make mapping infrastructure easier to deploy, operate and integrate — without requiring a complex server stack.

### What we're exploring

- **Vector tiles** — Efficiently serve map data from lightweight storage formats.
- **Geocoding** — Search locations using local datasets and external providers.
- **Routing** — Provide basic route calculations with optional external service integrations.
- **Developer-friendly integration** — Simple APIs, straightforward configuration and minimal dependencies.

### Project status

🚧 **Early development / Proof of concept**

MapCova is currently in the technical validation phase. Features, architecture and deployment requirements are subject to change.
