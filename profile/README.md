# MapCova

**Your maps. Your data. Your control.**

MapCova is a self-hosted vector tile server written in plain PHP. It runs on a
dedicated server with Docker or on inexpensive shared PHP hosting, with no
framework and no Composer packages in production.

### What it does

- **Vector tiles:** serves PMTiles and MBTiles to MapLibre GL JS, with guided
  import of areas from public tile repositories and automatic updates.
- **Styles:** pre-generated Protomaps styles, a style editor and composite maps.
- **Access control:** domain allowlist, API keys for server clients, statistics.
- **Geocoding and routing:** address suggestion, lookup and reverse geocoding,
  and simple routing, through the instance's own gateway.
- **Admin console** in six languages (German, English, Spanish, French, Italian,
  Portuguese), with signed one-click updates.
