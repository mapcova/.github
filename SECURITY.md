# Security policy

This is the default policy for the repositories of the MapCova organisation. A
repository with its own `SECURITY.md` follows that file instead.

## Reporting a vulnerability

Please do not open a public issue or discussion.

1. **Preferred:** use GitHub's private vulnerability reporting on the affected
   repository ("Security" tab, then "Report a vulnerability").
2. **Or** write to <hello@mapcova.com> with "SECURITY" in the subject. PGP
   encryption is not available; prefer the GitHub form for sensitive details.

Include the affected repository and version, a description, the impact and steps
to reproduce.

## What to expect

- Acknowledgement within 72 hours.
- A first assessment within 7 days.
- A fix for a confirmed critical or high issue within about 30 days; we tell you
  if we need longer.
- Coordinated disclosure: please allow up to 90 days before going public. We
  credit reporters unless they prefer to stay anonymous. There is no bug bounty.

## Scope and safe harbour

In scope: the code and services published by the MapCova organisation. Out of
scope: instances run by others (report to their operator), third-party
components (report upstream), and findings that need a compromised
administrator account or server.

If you act in good faith, avoid privacy violations, data destruction and service
disruption, and report promptly, we will not take or support legal action
against you.
