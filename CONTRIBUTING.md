# Contributing to MapCova

Thank you for helping. This is the short default guide for the repositories of
the MapCova organisation. If a repository has its own `CONTRIBUTING.md`, that
file takes precedence.

- Everyone follows the [Code of Conduct](CODE_OF_CONDUCT.md).
- Discuss features and larger changes in an issue or discussion before writing
  code. Small, obvious fixes can go straight to a pull request.
- Keep pull requests small and focused, one feature or fix each.
- Use Conventional Commits (`feat(scope): imperative summary`, with the reason in
  the body). Maintainers squash-merge.
- Add tests for changes of behaviour and update the documentation.
- Contributions to the core require signing the Contributor License Agreement;
  see `CONTRIBUTING.md` and `CLA.md` in the
  [mapcova/mapcova](https://github.com/mapcova/mapcova) repository.
- Report vulnerabilities privately: [SECURITY.md](SECURITY.md).
- Releases are cut and signed only by maintainers.
